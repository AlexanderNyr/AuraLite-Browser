Rust Browser

A browser written from scratch in Rust: our own HTML parser, our own CSS engine, our own block and inline layout, and a software rasteriser that writes straight into a framebuffer.

What works today

  • Tabs, back/forward history and reload
  • HTTP and HTTPS fetching, redirects and linked stylesheets
  • Word wrap, margins, padding, colours and bold / italic runs
  • Clickable links — hover one and the target shows up in the status bar

Styling above comes from the page's own CSS: see the coloured headings and the padded card. External stylesheets are fetched over the network and applied with a specificity cascade.
